# HYPERDRIVE 4.0 · Tour overhaul

## Play and progression

- Seeded encounter phrases replace repeated rows. Learn basic hearts and lift first; later roads introduce readable guards, moving crowds, committed dashes and elite anchors.
- Three current-car build families offer nine behavior-changing modules: piercing/chain/recycle hearts, EV guard/charged shots/guard penetration, and controlled descent/rush waves/jump energy.
- Four installed slots and one purchase per stop create real tradeoffs. A fifth module requires explicit replacement, with no refund or same-tour repurchase.
- Destination goals reward charging, attainable crowd conversions/combos or careful rush driving. Goals are bounded by the actual seeded opportunities, with spare conversion capacity.
- The safe EV route intentionally remains forgiving, while event/service roads offer greater rewards and denser hazards. Retry restores the exact departure checkpoint.

## Presentation and access

- Original detailed district, vehicle, duo, umbrella and console artwork is preserved.
- Tour-ticket title, six-city progress ribbon, arrival receipt, clear route-goal preview and dedicated build workshop.
- Contextual action guidance, next-EV distance, low-resource meter outlines, above-weather guard/tell labels and bounded hit/reward effects.
- Optional automatic held hearts in the pause menu. All four original actions remain available by keyboard and touch.
- Jump explicitly escapes held charging. Upgraded EV-range fringes are offered only when safe; an upgrade cannot trap controls beside an exterior hazard.
- Final DJ performance now has an optional eight-phrase encore using the same four actions. Generous hold windows, no rhythm exam, and completion points are already secured before it begins.

## Preserved contracts

- Twelve playable legs across six cities, direct destination-node choices and all existing illustrated districts/seasons.
- Car unlocks/selection remain new-run-only; ordinary tour coins fund current-car improvements.
- One persistent SoundCloud iframe, native player access without a sound-menu prerequisite, and no scene-transition remount.
- Always-on world/crew animation, Kansai Japanese copy, deterministic 120 Hz simulation and safe checkpoint migration.
- No new runtime dependency, telemetry, account, payment flow, deployment or publication.
